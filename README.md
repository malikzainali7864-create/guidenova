# GuideNova Production Starter

A production-oriented Next.js content-site foundation.

## Included
- Responsive homepage and navigation
- Category pages
- Individual article routes
- Metadata and Open Graph basics
- robots.txt and XML sitemap generation
- About, Contact, Privacy, Terms and Disclaimer pages
- Newsletter UI
- AdSense-ready ad placeholders
- Mobile responsive CSS

## Before launch
Replace the placeholder legal copy with reviewed policies, connect a real CMS/database, implement real search and newsletter processing, add original article content and images, configure analytics/consent, and replace `guidenova.com` if the final domain differs.

## Run
npm install
npm run dev

Production:
npm run build
npm start
